# PawBridge Python 에이전트 지침

저장소 루트 `CLAUDE.md`(판단 근거, 작업 단위 승인, Git·PR, 비밀정보)를 먼저 따른다. 이 파일은 `python/`에만 해당하는 규칙을 더한다. 현재 구성과 실행 위치는 `python/README.md`를 본다.

## API·모델·데이터 계약

- 요청·응답 필드, 오류 상태, 시간 제한이나 내부 인증을 바꾸면 호출하는 백엔드(`backend-app`)와 배포 설정을 함께 확인한다.
- 챗봇(`app.entrypoints.chatbot_api`), 실종동물 검색·추천·갤러리(`app.entrypoints.vision_api`, `app.entrypoints.gallery_cli`), 사진 압축(`app.entrypoints.photo_api`)의 실행 경로를 구분한다. 한 경로의 변경을 다른 경로의 기본값 변경으로 확대하지 않는다.
- 모델 버전, 벡터 차원, 전처리, 정규화, 점수 방식과 저장된 갤러리의 호환성을 함께 확인한다. 다른 모델의 벡터를 기존 갤러리에 덮어쓰지 않는다.
- 갤러리 생성의 입력 완전성, 중단·재시작, 상태 기록, 공개 전 검증과 실패 시 기존 공개본 유지 계약을 보존한다. 상태 디렉터리의 파일 이름은 운영 상태와 이어지므로 바꾸지 않는다.
- 이미지·다운로드 처리는 크기, 시간 제한, 실패 응답과 임시 파일 정리를 확인한다.
- GPU 메모리, 동시 추론과 프로세스 수는 실행 프로필의 실제 제한을 따른다. 가중치 다운로드나 갤러리 전체 재생성을 작은 시험처럼 실행하지 않는다.

## 검증

- 병합 전 로컬 시험과 운영 빌드 절차는 `python/README.md`의 "로컬 시험", "운영 빌드와 배포"를 따른다. GitHub Actions는 컴파일만 확인한다. 운영과 다른 의존성을 임의로 설치해 결과를 맞추지 않는다.
- 모델 가중치, GPU, DB가 필요한 검증은 실제 실행 여부와 환경 제한을 나눠 보고한다. 모의 시험 결과를 검색 품질이나 GPU 운영 검증으로 표현하지 않는다.
- API 변경은 정상 응답뿐 아니라 실패·입력 제한·인증 경계를, 저장·갤러리 변경은 재시도·복구·공개 경계를 확인한다.

## 운영 변경

- 운영 `.env`, 인증키, 서명 URL, 가중치 파일, 사진 원본, 갤러리 데이터, 로그와 `__pycache__` 같은 생성 파일을 커밋하지 않는다.
- 갤러리 공개·삭제, DB 변경, 운영 프로세스 재시작과 배포는 승인된 대상·범위·롤백 방법을 확인한 뒤 실행한다.
